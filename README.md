# Aplikasi Web Pengajuan Layanan Perbaikan Perangkat TI

Aplikasi web yang dikembangkan untuk membantu proses pengajuan
dan pengelolaan layanan perbaikan perangkat TI.

## Fitur

- Login User dan Admin
- Pengajuan layanan perbaikan
- Riwayat pengajuan
- Dashboard Admin
- Pengelolaan pengajuan
- Update status pengajuan
- Pemberian respons kepada pengguna

## Teknologi

- PHP
- MySQL
- HTML
- CSS
- Bootstrap

## Role

### User
- Login
- Mengajukan layanan perbaikan
- Melihat riwayat pengajuan
- Melihat status pengajuan

### Admin
- Login
- Melihat riwayat pengajuan
- Mengelola pengajuan
- Memberikan respons
- Mengubah status pengajuan

## Project Purpose

Aplikasi ini dibuat untuk membantu proses pengajuan
layanan perbaikan perangkat TI agar lebih terstruktur
dan mudah dipantau oleh pengguna maupun admin.
