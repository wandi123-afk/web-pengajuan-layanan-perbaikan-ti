# Aplikasi Web Pengajuan Layanan Perbaikan Perangkat TI

Aplikasi web untuk membantu pengguna mengajukan layanan perbaikan perangkat TI serta membantu admin dalam mengelola dan memantau pengajuan.

## Fitur

* Login User dan Admin
* Pengajuan layanan perbaikan
* Riwayat pengajuan
* Dashboard Admin
* Pengelolaan pengajuan
* Update status pengajuan
* Pemberian respons kepada pengguna

## Teknologi

* PHP
* MySQL
* HTML5
* CSS3
* JavaScript
* Bootstrap
* XAMPP

## Role

### User

* Login
* Mengajukan layanan perbaikan
* Melihat riwayat pengajuan
* Melihat status pengajuan

### Admin

* Login
* Melihat seluruh pengajuan
* Mengelola pengajuan
* Memberikan respons
* Mengubah status pengajuan

## Cara Menjalankan

1. Install XAMPP
2. Aktifkan Apache dan MySQL
3. Clone repository
4. Letakkan project di folder `htdocs`
5. Buat database `layanan_db`
6. Import `layanan_db.sql`
7. Sesuaikan konfigurasi database
8. Jalankan melalui browser

## Project Purpose

Aplikasi ini dibuat untuk membantu proses pengajuan layanan perbaikan perangkat TI agar lebih terstruktur dan mudah dipantau oleh pengguna maupun admin.
